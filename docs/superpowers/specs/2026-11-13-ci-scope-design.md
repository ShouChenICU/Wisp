# CI 验证范围设计

用户已批准按风险精简日常检查，保留完整发布检查。

- 日常检查始终执行格式、分层、资源预算、翻译一致性、生成文件一致性、构建和 C++ 回归测试。
- 模拟器日常覆盖启动、外设缺失降级、网络、场景运行与错误处理、Agent 对话；完整检查运行原有全部冒烟场景。
- 工具自测按工具及输入文件的变化选择；无法确定比较基线时运行全部。检查脚本或依赖变化同样运行全部。
- 布局覆盖屏幕形状和语言，纯手势仅覆盖形状。截图预览显式手动运行。
- 不为缩短 CI 修改产品定时逻辑，也不删除存储恢复、线程约束、安全和超时行为的回归检查。
- PR 和功能分支使用日常检查，main 和手动发布检查使用完整模式。
