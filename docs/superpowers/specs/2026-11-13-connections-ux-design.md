# 模型与 Wi-Fi 设置交互改版

状态：Wi-Fi 详情、显式断开、关闭后列表与状态栏隐藏已修订；124 项专项测试及圆屏固件编译通过，已刷入圆屏，待用户实测。完整检查记录见实施计划。

## 真机反馈后的 Wi-Fi 修订

用户要求以 iOS 审美重构现有 Wi-Fi 交互，以下约定替代第 3、4 节的对应细节。这是现有设置交互的修复；按后续用户要求补充显式断开服务，其语义同步至连接设计 4.2/5.1。

- 分组列表沿用 Wisp 的夜蓝表面、浅蓝强调色、文字色及主题开关，不单独指定 iOS 颜色。网络名单行优先，锁和信号使用图标，仅错误、等待、未在附近等有用状态保留文字。当前网络以勾标识；详情使用独立的信息图标，触控区不小于 48 px，不能触发整行连接。
- 扫描时只让原刷新图标绕自身中心匀速旋转，保留控件位置、尺寸和形状，禁止重复提交；完成或提交失败即停止并复位。手机配网保持带图标的次级入口，与上方网络列表留出至少一个主题大间距（24 px）。
- 密码与详情是列表的同级视图，进入时隐藏整个列表，不再隐藏其子项或通过滚动补偿定位表单。网络刷新不改变编辑视图位置，不重建键盘或丢失焦点、输入。
- 密码页在安全区和状态区下使用紧凑导航行：返回图标、SSID 与密码/校验说明、确认图标；下一行是密码框与眼睛图标。导航和输入行固定在键盘上方，禁用纵向滚动，文字和图标均在触控区内水平、垂直居中。
- 长度不足时确认图标禁用，键盘完成键仍执行校验并保留输入；校验说明显示在导航标题副行，不增加表单高度。取消、右滑或离页隐藏键盘并清空密码；详情视图保留完整名称与文字说明。
- 增加真实触控进入、连续状态刷新、焦点变化、图标命中区与居中、不同语言和屏形的回归验证；不再只检查打开表单的瞬间。

本设计修订 `2026-11-13-settings-model-shortcuts-design.md` 的第 3.1、6 节页面交互，其余服务、线程、持久化和插电保网约定保持适用。页面继续遵循 MVP 系统外壳与基础屏形规范。

## 1. 问题与目标

现版每项配置或网络都展开多行元信息和独占整行的操作按钮，圆屏首屏容纳的有效选项过少；扫描、测试和连接结果统一写在页顶，离开首屏后失去上下文；密码编辑器追加在列表末尾，连接与取消容易落到键盘后面。后台管理说明和地址占用了模型选择页最重要的首屏空间。

目标是先看清当前状态，再直接选择目标，操作反馈紧跟对象。沿用系统黑底、表面色、强调色、字体和触控尺寸，不另做一套主题。

可点击交互草图：仓库根目录 `build/design/connections-preview.html`。它用于评审列表密度和操作关系，采用演示数据；不是 LVGL 截图，浏览器输入框不代表设备键盘的最终布局。

## 2. 模型选择

- 标题下使用与 Wi-Fi 一致的 Wisp 配色和页面边距；已有配置放在同一张分组卡中，以细线分隔，每项以配置名称为主、模型名为辅。当前项左侧用勾标识，右侧使用展开/收起箭头。
- 点击整行展开该配置的操作区，同一时刻只展开一项；再次点击收起。名称、模型长文本在列表中省略，在展开后可完整换行查看。
- 展开操作区使用次级表面和纵向操作行，刷新图标对应“测试连接”、勾图标对应“使用此配置”，文字解释操作含义，避免两个含义相近的孤立图标。操作行触控高度不小于 48 px，内容垂直居中。当前项只提供测试，不提供重复激活。
- 测试中在原按钮和该项内显示进度；禁用不能同时执行的操作，有明确的禁用样式。测试结果和延迟留在该项，失败显示本地化原因和可重试入口，不要求滚到页顶寻找结果。
- 激活成功后更新当前标记、收起操作区，并保留原滚动位置；失败留在展开项内，原激活状态不变。测试和激活仍相互独立，不增加确认弹窗。
- 列表底部以独立分组提供带设置图标的“管理服务商”入口，与配置列表留出 24 px 间距；点击才展开后台地址与说明。无配置时直接显示简短空状态和管理引导。

## 3. Wi-Fi 列表

- 顶部状态卡只有开关与当前连接摘要：SSID 为主，状态和易懂的信号等级为辅。IP 和原始 dBm 放进网络详情，不挤占首屏。
- 下方为“附近网络”分组，标题右侧提供可点击的刷新操作；扫描中只旋转原刷新图标，完成后停止并复位，不增加文字或独立等待控件。
- 网络列表采用紧凑两行整行触控：SSID，加一条最有用的状态（连接中、密码错误、已保存、需要密码或开放网络），右侧显示信号。当前连接不在附近列表重复出现。扫描结果按信号排列，未扫描到的已保存项排在后面并标为不在附近。
- 点击已保存网络直接连接，点击未保存的开放网络直接连接；连接中和失败反馈留在目标网络行，成功后进入顶部当前连接区。
- 当前网络和已保存网络提供明确的详情入口，详情显示完整名称、连接状态、保存状态、安全性，以及当前连接的 IP、信号等级和原始 dBm；当前连接只提供“断开连接”和适用的“重新输入密码”，未连接项提供“连接”等适用操作。主要连接触控区和详情触控区均至少 48 px，不依赖长按或只有图标的隐蔽手势。
- 关闭 Wi-Fi 时立即移除当前连接与全部网络条目，隐藏附近列表、刷新和手机配网；下拉状态栏隐藏 Wi-Fi 图标和文字。后台提交失败时恢复实际状态。关闭 Wi-Fi 后，保留开关与一句关闭状态。重新开启恢复自动连接，并刷新附近网络。扫描失败与没有网络是不同空状态，前者允许重试。
- “通过手机配网”放在列表底部作为次入口，继续使用现有系统配网卡片。

## 4. 密码输入

- 选择需要密码的网络后打开模态密码弹窗，保留原列表或详情与滚动位置。弹窗提供 SSID、取消图标、密码框、显示/隐藏和连接图标；取消隐藏键盘并清空密码，不保存。
- 进入后直接弹出系统键盘，密码默认隐藏。弹窗输入区、连接入口和校验信息保持在键盘上方，键盘置于模态遮罩之上保证可触达。键盘完成键与连接按钮提交同一操作；取消键关闭弹窗。弹窗打开时阻止页面切换手势。
- 网络详情使用标准页面骨架，不显示左上返回图标；右滑由 Shell 的跟手过渡先返回网络列表，再右滑返回设置。详情所有文字区域均支持上下拖动滚动，分组布局遵循统一控件间距。
- 详情分为网络概况、无线信息、已连接网络的地址配置与操作组。无线信息展示扫描/连接获得的信号、加密协议、信道和接入点 BSSID；已连接项增加 IP、子网掩码、路由器、DNS 和设备 MAC。服务透传 HAL 可选元数据，ESP 适配层读取真实驱动信息；不可读取的字段不显示，未连接项不显示其他网络的地址信息。
- 长度错误贴近输入框显示并保留输入；连接认证失败在对应网络行显示“密码错误”，点击可重新输入。其他连接失败不误报为密码错误。

## 5. 反馈、屏形与生命周期

- 所有新建或修改的布局遵循 `docs/ui-style-guide.md`：独立控件之间至少留 `kGapSm`（8 px），信息与操作之间留 `kGap`（16 px），分组之间留 `kGapLg`（24 px）；不能用控件内部 padding 冒充控件间距。Wi-Fi 详情的连接与修改密码按钮必须分开。模型展开箭头与 Wi-Fi 行右侧的锁、信号和详情图标，均相对整行垂直居中，以布局后的实际坐标验收。

- 删除页顶永久占位的通用结果区；反馈归属配置、网络、开关或空状态。成功、失败、等待均包含文字，不只改变颜色。
- 提交后台失败时立即恢复控件，错误放在发起操作的位置。Wi-Fi 开关提交中显示过渡状态，避免周期刷新把尚未完成的用户选择立即拨回。
- 原列表状态、展开对象和输入视图有明确的页面内状态，不在每秒刷新时清空重建正在交互的控件。刷新只更新变化的状态，保留滚动、输入和焦点。
- 所有布局由安全区、可见行宽和系统状态区推导；首末项均可完全滚入可见区域。圆屏不在窄边放固定操作条，键盘上方的输入区按实际剩余可见高度布局。矩形和圆角矩形使用同一交互。
- 中、英、日文同步；不引入新的 UI 线程网络/flash 调用。离页、语言切换后的异步结果继续受生命周期保护。

## 6. 验收

- 模拟器生成方屏、圆屏的模型列表、展开/测试反馈、Wi-Fi 列表、密码键盘四类截图，先检查视觉层级，再做设备交付。
- 测试覆盖单项展开、反馈归属、测试不激活、激活失败、长名称、网页修改同步、刷新与空状态、开关提交状态、保存网络直连、密码校验/取消/键盘提交、两级返回及异步离页。
- 覆盖矩形、圆角矩形、圆形及中英日文；重点验证 360 px 圆屏与设备 466 px 圆屏，检查按钮可触达、首末项可见和键盘遮挡。
- 完成相关测试与完整 CI、圆屏固件编译；刷机及真机验收按用户授权执行，不将模拟器结果表述为设备实测。
