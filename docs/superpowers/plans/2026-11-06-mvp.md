# Wisp MVP 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 一台能独立使用的设备：按住 BOOT 键、长按或点一下鬼火就能和 Agent 语音对话（屏幕文字 + 朗读）；Agent 能记住偏好、建带提醒的待办、当场写出并打开场景；鬼火主界面加手势导航（设置、场景列表、对话记录）；网页"对话"页同时可用。

**Architecture:** 在裁剪后的 4a Agent 核心之上增加：`wisp_core` 的 `MemoryStore` 与 `ReminderScheduler`；新组件 `wisp_voice`（`VoiceService`、`PcmPlayer`、`SayParser`、VAD），分层在 `wisp_net` 与 `wisp_admin` 之间；新组件 `wisp_shell`（`ConversationController`、主界面、子页、导航、场景内说话浮层），分层在 `wisp_agent` 与 `wisp_app` 之间。鬼火渲染器 `ui::WispView` 在 `wisp_ui` 里独立开发。`wisp_app` 把自检界面承担的系统职责拆到常驻的 `SystemDuties`，开机进入主界面。

**Tech Stack:** C++20（`-fno-exceptions -fno-rtti`）、LVGL 9.5.0、Lua 5.5.1、ESP-IDF v6.0.3、ArduinoJson（经 `wisp/base/json.hpp`）、GoogleTest、Preact + htm（网页）、Python 3 标准库（`tools/fake_openai.py`、冒烟测试）。

**Status:** 待用户审阅；Task 0 完成后开始执行。

**Spec:** `docs/superpowers/specs/2026-11-06-mvp-design.md`（下文"spec N"指它）。"4a 计划"指 `docs/superpowers/plans/2026-11-05-agent-core.md`，"4a spec"、"3a spec"、"3b-1 spec"、"连接 spec"、"基础 spec"同各自文件。

## Global Constraints

- 分层（spec 1.4）：`wisp_base → wisp_os → wisp_hal → wisp_core → wisp_net → wisp_voice → wisp_admin → wisp_ui → wisp_scene → wisp_agent → wisp_shell → wisp_app`，`tools/check_layering.py` 强制；可移植层不 include 平台头文件（AGENTS.md 第 3 节清单）。
- 板子无关：GPIO0 只出现在 `boards/`；可移植层经按键 caps 找"对话"键（M6）。
- 服务层：Agent 工具、REST、设置页只调服务 API（`MemoryStore`、`ReminderScheduler`、`SystemSettings`、`SceneWiring`），不碰驱动。
- 屏幕形状：按 `hal::safe_rect()`/`row_span()` 布局，滚到两端首尾完整可见（3a spec 5.6）；界面测试覆盖 480×480 的 `rect`、`rounded_rect`（半径 70）、`circle`。
- UI 单线程：只有 UI 线程调 LVGL，其他线程经 `UiRuntime::post()`/`run_blocking()`。
- 存储：持久化写入走 `StorageManager::write_atomic`（对话日志沿用 4a 细化 6 的 `append()` 例外）。
- C++20，`-fno-exceptions -fno-rtti`，不用 `dynamic_cast`/`typeid`，错误经 `wisp::Result<T>`。
- 命名：新命名空间 `wisp::voice`、`wisp::shell`；组件 CMake 用 `wisp_component(...)`。
- 配置键 ≤ 15 字符：新增 `voice`/`tts_mute`（布尔，默认 false）。
- 内存：录音缓冲 `Mem::Large`，最长 30 s（960000 字节）；TTS 环形缓冲 `Mem::Large` 约 2 s；鬼火亮度图、色表、帧缓冲在 PSRAM；内部 RAM 只放 I2S 的 `Mem::Dma`。
- 任务：`wisp.agent`、`wisp.voice`、`wisp.play` 声明 `flash_access = false`，栈在 PSRAM；`wisp.agent.io` 声明 `true`，栈在内部 RAM；栈按 `mem` 实测 high-water mark 加 25%。
- TLS：同时最多 2 个模型连接（LLM 流 + 第一句 TTS），其余按顺序（spec 4.5）。
- 隐私：API Key 只经 `ModelProfileService::active_for_request(kind)` 取得、只进请求头；日志不记录录音、识别文字、记忆与待办内容、请求与回复内容。
- 注释只解释现状；不写评审轮次、不引用 `.superpowers/`、不用"Task N"（`tools/ci.sh` 守卫）。
- 测试：GoogleTest、TDD、输出干净；能在模拟器验证的不依赖真机。
- 流程（spec 1.3）：只当场修 Critical/Important；Minor 写进 `docs/backlog.md`；修复不复审，主控看 diff；标"批审"的任务批量评审。
- 提交：Conventional Commits，结尾 `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`；不 push。
- 验证：`cmake -S simulator -B build/sim -G Ninja && cmake --build build/sim && ctest --test-dir build/sim -R '<正则>' --output-on-failure`；提交前 `bash tools/ci.sh`；固件 `bash -c '. ~/esp/esp-idf-v6.0.3/export.sh >/dev/null && cd firmware && idf.py build'`。
- 收音常量（`wisp/voice/limits.hpp`）：`kSampleRate = 16000`、`kFrameMs = 20`、`kMaxRecordMs = 30000`、`kHoldStartMs = 300`、`kNoiseEstimateMs = 300`、`kStartTimeoutMs = 5000`、`kEndSilenceMs = 800`、`kMinSpeechMs = 300`。
- 识别与朗读常量：`kAsrTimeoutMs = 15000`、`kAsrRetries = 1`（429/5xx）、`kTtsMaxChars = 200`（码点）、`kTtsDefaultRate = 24000`、`kTtsTimeoutMs = 15000`、`kRingMs = 2000`、`kLevelIntervalMs = 50`（20 Hz）、`kWavHeaderBytes = 44`；分句符 `。！？!?；;` 与换行。

## Review Focus

1. **连续、交叠的触发**：识别中又点鬼火、朗读刚开始就按住再松开 BOOT 键、网页一轮进行中按住说话。期望：任何时刻最多一轮在跑、最多一路收音；被打断的一轮记"已中止"；最终 `idle`，唤醒锁全部释放。测试：Task 17 `ConversationTest.RapidTriggersNeverOverlapTurns`。
2. **语音一轮中途断网**（上传录音时、TTS 流式返回中）。期望：`voice.state = error`，`reason` 为 `offline` 或 `asr_failed`/`tts_failed`；文字照常显示；播放停止；三把锁释放；不卡在 `transcribing`/`speaking`。测试：Task 16 `VoiceServiceTest.TransportErrorDuringAsrIsReported`、`VoiceServiceTest.NetworkLossMidSpeechEndsCleanly`。
3. **时钟跳变**（开机后第一次校时把时钟拨快几小时，或往回拨）。期望：跨过的提醒合并成一条"错过 N 个提醒"，每条只报一次；往回拨不会让响过的提醒再响。测试：Task 12 `Reminders.ClockJumpForwardReportsMissedOnce`、`Reminders.ClockJumpBackDoesNotRefire`。
4. **模型连接超过 2 个**（第一句 TTS 与 LLM 流并发时，第二句或下一次工具后的 LLM 请求又到）。期望：任何时刻 ≤ 2。测试：Task 17 `ConversationTest.AtMostTwoModelConnectionsInAVoiceTurn`。
5. **模型乱用 `<say>`**：只有 `</say>`、`<say>` 里再套 `<say>`、大写标记、say 超过 200 字。期望：多余的结束标记与嵌套的开始标记丢掉；大写的按普通文字；朗读到第 200 个码点，屏幕显示全文。测试：Task 14 `SayParser.StrayCloseTagIsDropped`、`NestedOpenTagIsDropped`、`TagsAreCaseSensitive`；Task 16 `VoiceServiceTest.CapsSpeechAt200Chars`。

## 相对 spec 的细化（执行前请用户确认）

- **M1 来源**：`enum class Source : uint8_t { Voice, DeviceText, Web }`，字符串 `"voice"`、`"device_text"`、`"web"`。`AgentService::submit(text, source)` 取代 4a 的 `send(text, Origin)`；user 消息存 `source`；`POST /agent/messages` 用 `Web`。
- **M2 Agent 事件**：`AgentService` 支持多个监听者（WS 与 `ConversationController` 都订阅）；新增事件 `TurnBegin`（`source`、用户文字、`turn`）、`TurnEnd`（结束状态）；删除 4a 的 `SceneShown`。
- **M3 提醒通知**：spec 的 `source = "system.reminder"` 含点，不会与场景 id 冲突，作为保留来源加进 `NotificationService`，不受每分钟限额。标题按 `kTitleMax`（32 字节）在 UTF-8 边界截断加"…"，截断时正文放完整标题。`Notification` 增加 `action2`/`action2_arg` 并持久化；操作码 `todo_done`（"完成"）、`todo_snooze`（"10 分钟后"），参数为待办 id。带操作的横幅停留到被点、上划或 30 s（`SystemLayer::kActionBannerMs = 30000`，同 `TonePlayer::kAlarmMaxMs`）。待办完成或删除时撤下它的未读提醒。
- **M4 错过的提醒**：合并为 `source "system.reminder"`、`id "missed"`；标题由 App 注入的本地化函数生成（"错过 N 个提醒"），正文为标题列表（"、"连接，截到 `kBodyMax`）。"点开显示标题列表"由面板与横幅显示正文实现。
- **M5 上下文增补**：`DeviceSnapshot` 加 `memory`（每条 `"[<id>] <text>"`）、`weekday`（1 = 周一）、`source`。动态部分顺序：记忆 → 本地时间与星期 → 来源（`voice` 时要求正文简短）→ 4a 的场景、电量、网络。
- **M6 对话键**：按键 caps 增加可选键 `"role"`，取值 `"talk"`；本板与模拟器给 `button.vol_down` 设上。300 ms 由 `TalkKey` 从 `down` 起计时；不足 300 ms 的 `up` 不做事；熄屏时按键只唤醒（PowerManager 已有）。
- **M7 音频输出共用**：`TonePlayer` 与 `PcmPlayer` 不同时打开 `audio_out.main`。`TonePlayer::set_output_guard()` 每次 `play()` 时询问：`Alarm` → 先 `stop_speaking()` 并等播放关闭，再响（闹铃优先）；播放中的 `Tone` → 丢弃。开始收音的提示音播完（最多等 300 ms）再开麦克风。
- **M8 ASR 零拷贝**：`CaptureBuffer` 一次分配 `[512 B 头部预留][PCM][128 B 尾部预留]`；发送前把 multipart 字段与 WAV 头右对齐写进头部、结尾边界写进尾部，整段作为 `body_ref`。
- **M9 TTS 节奏**：`ConversationController` 按 `agent.state ∈ {thinking, output}` 调 `VoiceService::set_llm_busy()`。每轮第一句可以和 LLM 流并发；之后的句子等 `llm_busy == false`。`VoiceConfig::overlap_first_sentence = false` 时第一句也等（spec 4.5 的回退开关）。
- **M10 "没听清"**：VAD 开始超时、误触、ASR 返回空文字都不算错误：`voice.state` 回到 `idle` 并带 `"result":"not_heard"`。spec 4.6 的 `reason` 取值不变。按住说话同样统计有效语音，不足 300 ms 丢弃。
- **M11 点一下鬼火**：空闲 → 开始收音（VAD）；收音中 → 结束并发送；朗读中 → 停止朗读；识别中、思考中、执行工具中 → 不做事。按住说话在任何状态都先停朗读、中止进行中的一轮再收音；对话键按住期间，屏幕上划取消。
- **M12 `WispView` 补充**：加 `set_size(int)`（45% 与 28% 之间切换）、`obj()`、全局 `wisp_perf()`；表情插值 300 ms。
- **M13 代码块**：固件没有等宽字体，代码块用正文字体加 `kMutedSoft` 底色；等宽字体记入 backlog。
- **M14 对话记录的返回**：列表上下滚动，"上划返回"只在已滚到底（打开时就在底部）时生效，与下拉面板"内容在底部时上划关闭"一致。
- **M15 自检界面的系统职责**：电源键、配对码与配网卡片、恢复出厂与固件确认框、`WISP_PERF` 都在自检界面里。开机不再进自检界面，所以拆到常驻的 `app::SystemDuties`；自检界面只剩诊断内容，按需打开。
- **M16 假服务**：GoogleTest 用进程内 `tests/support/fake_models.hpp` 的 `FakeModelServer : net::HttpClient`，按路径分派到 4a 的 `FakeLlmServer`、ASR 脚本、TTS 脚本，记录全部请求与三类合计的 `max_concurrent()`。冒烟测试要真正的端点，沿用 4a 细化 31 扩展 `tools/fake_openai.py`。
- **M17 视觉探测**：MVP 没有 `vision` 的使用者，不做 `probe_vision`，记入 backlog。
- **M18 场景最近使用**：`shell::SceneRecents` 在 `<System>/shell/recents.json` 记 `{"version":1,"recent":{"<id>":<seq>}}`，收到 `scene.state running` 时更新，在 `wisp.fs` 上合并 1 s 写一次；恢复出厂删除 `<System>/shell/`。
- **M19 冒烟日志**（只有元信息）：`agent: turn <n> start source=<s>`；`agent: state <s>`；`voice: state <s>`（加 `reason=`/`result=`）；`voice: asr ms= bytes= status=`；`voice: tts n= chars= ms= status=`；`reminder: fired id=<id>`；`shell: page <name>`。
- **M20 `agent_done`**：熄屏完成通知保留（4a spec 3.7），点击打开主界面。
- **M21 `tts_mute`**：`SystemSettings` 键 `tts_mute` → `voice`/`tts_mute`，进入 `to_map()`、`GET/PUT /settings` 与 `system.settings`。
- **M22 TTS 请求**：每句一个，超时 15 s，不重试；失败发 `tts_failed`，这一轮余下的句子不读。
- **M23 模型选项**（spec 2）：`asr.language`（1–8 字节 `[A-Za-z-]`）；`tts.voice`（1–64 字节）、`tts.sample_rate`（整数 8000–48000，缺省 24000）、`tts.speed`（0.25–4.0）。只对对应类型有效，出现在别的类型上返回 `InvalidArgument`。管理后台在已有的模型页加这些字段（spec 1.4"只新增记忆页"指新页面）。
- **M24 时钟未设置**：`wall_s() < 1704067200`（与 `scene::MinuteTicker::kValidSince` 相同），定义为 `core::kWallClockValidSince`。
- **M25 `WISP_PERF`**：加 `wisp_fps`、`wisp_ms`（最近 5 s 鬼火的出帧率和每帧平均耗时，没出帧为 0）。Task 10 先加在自检界面的输出里，Task 18 把输出移到 `SystemDuties`。

写计划时在 `wisp-3b` 核实过各任务 Consumes 里的 3b-1 名称（`NotificationService`、`SystemLayer`、`WakeLockRegistry`、`PowerManager`、`PowerKeyController`、`TonePlayer`、`hal::AudioIn/AudioOut`、`ButtonService`、`ModelProfileService`、`SystemSettings`、`SceneFiles`、`SceneWiring::request_delete`、`SimClock`、`debug_command()`），以代码为准。

`SayParser`（一轮内跨多次模型请求保持状态，一轮开始 `reset()`）：

```
tags open "<say>", close "</say>" (exact); state Outside|Inside; pending = ""
feed(d): pending += d; loop:
  tag = Outside ? open : close;  other = Outside ? close : open
  i = find(tag); j = find(other)
  if j found and (i not found or j < i): emit(pending[0:j]); erase `other`; continue   // stray / nested: dropped
  if i found: emit(pending[0:i]); pending = rest after tag; flip; continue
  keep = longest suffix of pending that is a proper prefix of open or close
  emit(all but keep); pending = keep; break
emit = Outside ? body : say
finish(): flush pending to the current side; if !saw_say: return first_sentence(this turn's body)
```

VAD（每帧 20 ms，`e` 为均方）：

```
t < 300 ms: noise = running mean of e; Continue
speech = e > max(noise * 6, 10000);  if !speech: noise += (e - noise) / 16
if !started: run = speech ? run + 1 : 0
             if run >= 3: started, speech_ms = 60
             elif Auto and t >= 5000: NoSpeech
else: speech ? (speech_ms += 20, silence = 0) : (silence += 20)
      if Auto and silence >= 800: return speech_ms < 300 ? TooShort : Done
finish(): speech_ms < 300 ? TooShort : Done
```
