# 设置页快捷模型、Wi-Fi 管理与编译期浅睡实施计划

状态：已获用户审核批准；功能已实现，主机验证与圆屏固件编译通过，待真机验收。

依据：`../specs/2026-11-13-settings-model-shortcuts-design.md`。原有模型配置、Wi-Fi 和电源服务继续分别遵守 connectivity-admin、scene-device 和 MVP 设计；冲突处按本次获批设计更新原文。

## 1. 编译期浅睡策略

1. 先补充失败测试：系统设置不再暴露或接受 `light_sleep`；旧存储值不改变策略；浅睡仅在深度待机且无 CPU 锁时开启。
2. 新增共享 CMake 选项 `WISP_ENABLE_LIGHT_SLEEP`（默认 ON），向应用编译目标传入布尔定义，覆盖模拟器和固件构建。PowerManager 删除动态设置缓存，改读编译常量。
3. 删除设备设置、网页表单、SystemSettings 值/序列化/接线及相关设置 schema 中的动态字段；更新文案和使用文档，保留电源诊断状态。
4. 在默认构建和独立 OFF 构建目录运行对应测试，验证关闭选项仍能深度待机且不请求开启浅睡。

## 2. Wi-Fi 用户启停服务

1. 先补 WifiService 测试：启停、关闭持久化及重启、关闭热点、不丢凭据、旧文件默认开启、手动关闭优先于电源级别和自动重连。
2. 扩展服务的用户启停 API 与状态快照，以单一有效状态计算协调用户开关和待机策略；`net/wifi.json` 增加可选 enabled 字段并沿用 LatestSave/StorageWorker。
3. 检查自动 tick、扫描、手动连接、配网热点及联网窗口全部路径，关闭时均不得绕过；并发关闭与扫描/连接返回不能重新启网。服务测试使用假 HAL 验证调用。

## 3. 插电保网

1. 先写供电策略测试：开机已插电、充满电但 USB 仍在、深度待机中插电、拔电、手动关网、其他唤醒锁并存和供电状态未知。
2. 在应用接线中使用 PowerMonitor 供电快照和 WifiService 用户状态，管理一把具名 network 唤醒锁。必要时为 PowerMonitor 增加线程安全的最近有效采样接口，复用现有采样，不让 UI 直接轮询驱动。
3. 首次采样和后续周期检查均能修正锁状态，不依赖单次事件投递；释放只影响本策略的锁，不改变用户活动时钟。

## 4. Wi-Fi 子页

1. 先写页面与接线测试：入口、开关、不可用、已保存/扫描列表、选网、密码输入与取消、连接状态、任务拒绝、关闭与离页后的过期结果。
2. 扩展 shell 子页导航，增加 ConnectionsPage 的 Wi-Fi 模式；现有 SettingsPage 的 Wi-Fi 行打开子页。按安全区与可见行宽布局，复用系统键盘、返回导航和配网卡片。
3. 后台扫描/连接通过服务执行；UI 仅使用无密码状态快照。复用或增加有界后台任务设施，不为每次点击创建无界任务，不在 flash 工作者上等待扫描。
4. 补全中英日文并验证三种屏形。保留热点配网入口。

## 5. 快捷模型子页

1. 先写失败测试：三类型入口、过滤、当前配置、空状态、测试/激活结果、网页修改同步、并发操作、任务拒绝、离页和语言重建。
2. 增加模型子页和 shell/app 依赖注入，列表、测试、激活复用 ModelProfileService。测试只探测连接，不隐式激活；已有请求继续使用其请求快照。
3. 网络探测异步执行，结果回 UI 线程；页面失效后丢弃回调。测试错误映射到本地化类别，不显示原始响应。页面提供网页后台地址与配置编辑引导。

## 6. 集成与交付

1. 使用本地假网络/模型服务完成模拟器操作验证，覆盖三种屏形、三种语言和异步离页；检查扫描、测试期间页面交互不阻塞。
2. 更新原始 specs 中被取代的动态浅睡、Wi-Fi 入口和设置分组描述，以及架构/使用文档中的相关接口说明。若 README 变化，三种语言同步。
3. 运行相关单元、UI、服务集成测试、开关 OFF 构建测试，以及 `bash tools/ci.sh`。不为纯文字调整编写镜像测试。
4. 提供真机验收步骤：两种设备的 Wi-Fi 扫描/密码输入/切换、关闭重启后保持关闭、插电灭屏持续联网、满电保网、拔电省电、模型切换，以及浅睡默认/关闭两种构建的待机唤醒。需要设备的项目交用户实测，不提前标记通过。
5. 提交、版本递增、合并和推送按用户后续授权执行；当前不进行发布。

## 7. 实施记录与真机验收

- 已实现编译期浅睡开关、模型快捷操作、Wi-Fi 子页和插电保网策略。Wi-Fi 用户开关持久化，优先于待机和插电策略；模型测试不会自动激活。
- 扫描、连接和模型探测使用独立的 `wisp.netcfg` 工作者，最多排队四项任务，栈使用默认非 hot、非 flash 配置。关闭时先处理已接受的操作，再销毁服务；失效页面不接收异步结果。
- 页面测试发现圆屏密码框可能被键盘遮挡，已通过临时增加滚动底部空间、按安全区和状态胶囊位置滚动修正，取消或离页时恢复布局并清除密码。
- 独立 `WISP_ENABLE_LIGHT_SLEEP=OFF` 构建的 47 项 PowerManager 测试通过。圆屏 `waveshare_esp32_s3_touch_amoled_1_75c` 固件使用 ESP-IDF 6.0.3 编译成功，尚未刷机。
- 最终 `CTEST_PARALLEL_LEVEL=4 bash tools/ci.sh` 通过：格式、分层、资源及字体生成一致性检查通过，全部 2,827 项测试（含模拟器与后台冒烟）通过。设置页测试单独运行 38 项通过，网络接线测试 6 项通过。原有屏形测试的分组数断言已从五组更新为六组，并纳入三类模型入口检查。

以下项目需要用户在方屏、圆屏各验收一次，当前均未标记为通过：

1. 设置 → Wi-Fi：扫描，连接开放网络和加密网络，输入错误密码后重新输入，切换已保存网络，取消密码输入及返回。检查圆屏文字、密码框、键盘和按钮均可见。
2. 关闭 Wi-Fi，等待保存后重启，应保持关闭且凭据保留；重新开启后可自动连接。插电时手动关闭同样生效。
3. 插电灭屏后持续访问后台，分别覆盖充电中和满电；深度待机中插电应恢复联网，但不点亮屏幕。拔电后无其他网络唤醒锁时应恢复原待机策略。
4. 分别测试、激活已有 LLM、ASR、TTS 配置，确认测试不切换当前配置；在网页新增、修改或删除后返回设备检查列表更新。测试期间返回或切换页面不得崩溃。
5. 默认固件和 `WISP_ENABLE_LIGHT_SLEEP=OFF` 固件分别检查待机及唤醒；关闭构建不得请求自动浅睡。
6. 扫描、模型探测、后台连接及 OTA 并发时运行 `mem`，检查 `wisp.netcfg` 栈余量，以及内部 RAM 最小空闲量和最大连续块符合 `ram_budget.hpp`；实测结果记录到对应硬件文档。
